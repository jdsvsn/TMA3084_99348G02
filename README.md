# TMA3084 SELAB - Lab 1: Pizza Order Calculator

## Description

A Dart program that calculates pizza order payments using a switch statement and a while loop.

## Pizza Prices

* Small: $5 USD
* Medium: $7 USD
* Large: $10 USD

## Features

* Accepts pizza size and quantity.
* Calculates the subtotal for each order.
* Supports continuous ordering.
* Displays the final total payment.

## How to Run

```bash
dart pizza_calculator.dart
```
